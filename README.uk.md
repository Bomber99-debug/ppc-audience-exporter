# PPC Audience Exporter

[English](README.md) | **Українська**

Python-утиліта для підготовки клієнтських аудиторій для PPC-реклами. Програма читає дані з Excel, хешує вибрані
персональні ідентифікатори алгоритмом SHA-256, розподіляє контакти за категоріями з окремого Excel-файлу, створює CSV та
завантажує їх на SFTP-сервер.

> **Основна версія:** `main_v.2.py`. Файл `main_v.1.py` залишено як окрему попередню реалізацію. Ця інструкція описує
> саме **v.2**, для якої наразі потрібне локальне налаштування та виправлення помилок, наведених нижче.

## Можливості

- Зчитування вибраних колонок із першого аркуша `.xlsx`.
- Розділення ПІБ на ім’я та прізвище.
- Хешування email, номера телефону, імені та прізвища за допомогою SHA-256.
- Створення загального CSV і окремих файлів аудиторій за категоріями.
- Завантаження створених файлів на SFTP-сервер через Paramiko.

## Вимоги

- Python **3.14 або новіший** (відповідно до `pyproject.toml`).
- [Poetry](https://python-poetry.org/) для встановлення залежностей.
- Залежності з `pyproject.toml`: `openpyxl`, `transliterate`, `paramiko`.
- Доступ до SFTP-сервера та локальний модуль `config.py`.

Встановлення залежностей без встановлення самого репозиторію як Python-пакета:

```bash
poetry install --no-root
```

## Вхідні файли

### Excel-файл із контактами

Версія 2 обробляє **один явно вказаний Excel-файл**, а не всю директорію. Використовує перший аркуш і фіксовані номери
колонок:

| Колонка Excel | Дані                          |
|---------------|-------------------------------|
| D (4)         | Email (`E mail`)              |
| E (5)         | ПІБ (`ФИО`)                   |
| F (6)         | Номер телефону (`№ телефона`) |
| G (7)         | Поштовий індекс (`Индекс`)    |
| I (9)         | Категорія (`Категория`)       |

Перший вибраний рядок вважається заголовком і пропускається. Шлях до вихідного `.xlsx` потрібно записати у змінну
`file_name_1` функції `main()` у файлі `main_v.2.py`.

### Файл категорій (`category.xlsx`)

Розмісти `category.xlsx` поруч зі скриптом. Кожна колонка задає окрему аудиторію: перша непорожня клітинка містить її
назву, а наступні непорожні клітинки перелічують категорії контактів, які до неї належать. Програма порівнює їх зі
значенням категорії у файлі контактів.

## Обробка даних і результати

Для кожного запису v.2:

- Видаляє звичайні пробіли з email, додає префікс `380` до непорожнього номера телефону та хешує ці значення SHA-256.
- Бере перші два слова з ПІБ як ім’я та прізвище; відсутні частини замінює на `Unknown`. Обидва значення також
  хешуються.
- Залишає поштовий індекс із джерела або підставляє `1001`, якщо значення порожнє.
- Встановлює код країни `ua`.
- Використовує категорію лише для розподілу записів, не додаючи її у фінальний CSV.

Кожен CSV записується в UTF-8 із роздільником-комою та такими колонками:

`Email, Phone, First Name, Last Name, Zip, Country`

Локально створюються:

- `category/all.csv` — загальна аудиторія.
- `category/<назва категорії>.csv` — окремий файл для кожної аудиторії з `category.xlsx`.

Програма завантажує `all.csv` і CSV кожної категорії в каталог, указаний у конфігурації SFTP. Назви віддалених файлів
категорій транслітеруються, переводяться в нижній регістр, а пробіли замінюються підкресленнями. Локальні назви
зберігаються мовою категорій.

## Налаштування SFTP

Обидві версії імпортують локальний модуль `config`, але **`config.py` навмисно виключений із Git**. Для запуску v.2
потрібно мати локальний модуль, який експортує об’єкт `config` із такими атрибутами:

| Атрибут               | Призначення                           |
|-----------------------|---------------------------------------|
| `sftp_host`           | Ім’я хоста або IP-адреса SFTP-сервера |
| `sftp_username`       | Ім’я користувача SFTP                 |
| `sftp_password`       | Пароль SFTP                           |
| `path_directory_sftp` | Каталог призначення на сервері        |

У v.2 використовується порт SFTP **22**. Каталог на сервері має існувати, а користувач повинен мати права на
завантаження файлів. Не додавай до Git паролі, конфігураційні файли, клієнтські таблиці або експортовані аудиторії.

## Запуск v.2

1. Встанови залежності через Poetry.
2. Підготуй таблицю контактів і `category.xlsx` у вказаному форматі.
3. Додай локальну конфігурацію SFTP та вкажи шлях до Excel-файлу в `main_v.2.py`.
4. Перед обробкою реальних даних виправ наведені нижче помилки поточної версії.
5. Запусти:

```bash
poetry run python main_v.2.py
```

## Відомі обмеження поточної v.2

- `file_name_1` за замовчуванням порожній: шлях потрібно задавати вручну.
- `rewrite_headers()` **перезаписує перший оброблений контакт** заголовком CSV, через що запис втрачається.
- Наприкінці скрипту є виклик неіснуючої функції `nput()`, який призведе до `NameError`, якщо виконання дійде до нього.
- Колонки вхідного Excel фіксовані; префікс телефону та резервний поштовий індекс задані жорстко, без повноцінної
  нормалізації та перевірки.
- У репозиторії немає `config.py` і демонстраційних Excel-файлів.

Перед використанням із реальними клієнтськими даними ці недоліки потрібно виправити.

## Конфіденційність і безпека

Клієнтські записи можуть залишатися персональними даними навіть після хешування SHA-256: **хешування не дорівнює
анонімізації**. Обробляй лише дані, на використання яких маєш належні підстави, і дотримуйся вимог законодавства та
рекламних платформ. Не зберігай вихідні файли, експорти й облікові дані в Git. Поточне SFTP-з’єднання також явно не
перевіряє ключ хоста сервера; перед робочим використанням варто додати таку перевірку.
